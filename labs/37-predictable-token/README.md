# Lab 37 — Recover

**Class:** predictable token / weak PRNG · **Difficulty:** ③

An account recovery flow. Tokens are 16 hex characters. You can see the tokens
issued to addresses you own (`…@example.test`); `admin@acme.test` you cannot.

    ./run.sh 37     →  http://127.0.0.1:9370

**Goal:** recover `admin@acme.test`.

**Hint:** issue yourself a few tokens and look at them next to each other, and
next to the clock.
